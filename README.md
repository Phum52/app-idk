# ตรวจเขต (แอปบันทึกการตรวจความสะอาดประจำวัน ออฟไลน์)

ตรวจทุกวันว่า ลานกีฬาเปตอง โต๊ะหินอ่อน ม้านั่งใต้ต้นจามจุรี สะอาดหรือไม่ ติ๊ก "สะอาด" หรือ "ไม่สะอาด"
แอปบอกวันที่ สัปดาห์ที่ของเดือน และสัปดาห์ที่ของปีให้ทุกวัน เก็บประวัติไว้ในเครื่อง ใช้ได้โดยไม่ต้องมีอินเทอร์เน็ต

## ใช้ยังไง

- แท็บ **วันนี้** ติ๊กทีละจุด ถ้าไม่สะอาดแตะเหตุผลสำเร็จรูป หรือพิมพ์สิ่งที่พบ มีโน้ตของวัน
- ลืมตรวจวันก่อน: กดลูกศรย้อนวัน หรือกด "เลือกวันที่" แล้วกรอกย้อนหลังได้
- แท็บ **ประวัติ** เห็นทุกวันแบ่งตามสัปดาห์ วันที่ไม่ได้ตรวจขึ้นว่า "ลืมตรวจ" กด "คัดลอก" เพื่อเอารายงานสัปดาห์ไปวาง LINE
- แท็บ **สรุป** ตรวจครบติดต่อกันกี่วัน ลืมตรวจกี่วัน แต่ละจุดสะอาดกี่เปอร์เซ็นต์ (เดือนนี้/ทั้งหมด)
- ตั้งค่า: เพิ่ม/เปลี่ยนชื่อ/เรียง/ลบจุดตรวจ, ชื่อเขต, เลือกสัปดาห์เริ่มวันจันทร์หรืออาทิตย์, แจ้งเตือนรายวัน, สำรอง/กู้คืนข้อมูล

## สัปดาห์ที่คิดยังไง

- สัปดาห์ที่ของเดือน: สัปดาห์ที่มีวันที่ 1 ของเดือนนับเป็นสัปดาห์ที่ 1
- สัปดาห์ที่ของปี: สัปดาห์ที่มีวันที่ 1 มกราคมนับเป็นสัปดาห์ที่ 1
- เริ่มสัปดาห์วันจันทร์ (เปลี่ยนเป็นอาทิตย์ได้ในตั้งค่า)

## ไฟล์ในโฟลเดอร์

- `inspect.html` ไฟล์เดียวรวมทุกอย่าง เปิดทดลองได้ทันที
- `www/` ซอร์สโค้ดแอป (index.html, style.css, app.js)
- `.github/workflows/build-apk.yml` ตัวสร้าง APK อัตโนมัติบน GitHub
- `build-standalone.py` สร้าง `inspect.html` ใหม่หลังแก้โค้ดใน `www/`

## ได้ไฟล์ APK (GitHub Actions)

1. สร้าง repository ใหม่ใน GitHub (Public)
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ (ลากทั้งโฟลเดอร์ `www` และ `resources` ได้)
3. สร้างไฟล์ `.github/workflows/build-apk.yml` ด้วยปุ่ม Add file → Create new file แล้ววางโค้ดจากไฟล์นี้
4. แท็บ **Actions** รอ Build APK เสร็จ แล้วโหลด `inspect-apk` ตรงหัวข้อ Artifacts
5. แตกซิป ได้ `app-debug.apk` ส่งเข้ามือถือแล้วติดตั้ง

## แจ้งเตือนรายวัน

- ใช้ได้เฉพาะ APK ที่สร้างจากชุดนี้ (ใช้ปลั๊กอิน Local Notifications ของ Capacitor) ไม่ทำงานบนเว็บ
- ตั้งค่า → แจ้งเตือนไม่ให้ลืมตรวจ → เลือกเวลา → เปิดแจ้งเตือน (Android 13 ขึ้นไปจะถามสิทธิ์แจ้งเตือน ให้กดอนุญาต)
- แจ้งเตือนทุกวันตามเวลาที่ตั้ง แม้วันนั้นตรวจครบแล้ว
- บางยี่ห้อ (เช่น Xiaomi, OPPO, Vivo, Huawei) ปิดแอปที่ไม่ได้ใช้เพื่อประหยัดแบตเตอรี่ ถ้าแจ้งเตือนไม่ขึ้นให้ตั้งแอปนี้เป็น "ไม่จำกัดแบตเตอรี่/อนุญาตทำงานเบื้องหลัง"

## หมายเหตุ

- APK เป็นแบบ debug ติดตั้งใช้เองได้ ถ้าจะขึ้น Play Store ต้องทำ release build และเซ็นกุญแจ
- ถอนการติดตั้งแอปหรือล้างข้อมูลแอปแล้วข้อมูลจะหาย ควรคัดลอกข้อมูลสำรองไว้เป็นระยะ
- เปลี่ยนไอคอนโดยแทนที่ `resources/icon.png` (1024x1024)
